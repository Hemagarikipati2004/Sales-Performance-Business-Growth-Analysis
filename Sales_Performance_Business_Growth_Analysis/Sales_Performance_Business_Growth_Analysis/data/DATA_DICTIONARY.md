# Data dictionary

| Column | Meaning |
|---|---|
| order_id | Unique order identifier |
| order_date | Order placement date |
| customer_id | Customer identifier |
| customer_segment | Consumer, Corporate or Small Business |
| region / city | Sales geography |
| sales_channel | Online, Retail Store, Wholesale or Unknown |
| category / product | Product grouping and product name |
| quantity | Units in the order |
| unit_price | Price per unit before discount |
| discount | Discount fraction (e.g. 0.10 = 10%) |
| revenue | Net sales after discount |
| cost | Estimated cost of goods |
| profit | Revenue minus cost |
| order_year / order_month / month_name / year_month | Derived calendar attributes |
