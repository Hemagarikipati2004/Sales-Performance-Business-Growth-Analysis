## 📊Sales-Performance-Business-Growth-Analysis
End-to-end sales analytics project using Python, SQL, and Streamlit.

## 📌 Project Overview

This project is an end-to-end Data Analytics solution developed to analyze sales performance, understand business trends, and identify growth opportunities using Python, SQL, and Streamlit.

The project uses a synthetic dataset containing 6,000 sales transactions.

## 🎯 Project Objectives

- Analyze overall sales and business performance.
- Identify top-performing products and regions.
- Evaluate revenue and profit trends.
- Understand customer and sales channel performance.
- Generate meaningful business insights.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SQL
- SQLite
- Streamlit

## 🔍 Key Features

- Data cleaning and preprocessing.
- Exploratory Data Analysis (EDA).
- Revenue and profit analysis.
- Monthly sales trend analysis.
- Regional performance analysis.
- Product and category analysis.
- Customer and sales channel analysis.
- Interactive Streamlit dashboard.

## ⚙️ Installation and Execution

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Install dependencies

```bash
python -m pip install -r requirements.txt
```

### 3. Clean the dataset

```bash
python src/clean_data.py
```

### 4. Run sales analysis

```bash
python src/analysis.py
```

### 5. Launch the dashboard

```bash
streamlit run app.py
```
